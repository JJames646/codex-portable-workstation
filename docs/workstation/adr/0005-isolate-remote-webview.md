# ADR-0005：服务器网站使用隔离远程 WebView

## 状态

Proposed

## 背景

用户要求在工作站内部打开完整服务器网站。远程页面如果与本地 Tauri UI 共享权限，可能调用文件、Shell、更新和凭据命令。

## 决策

使用独立 WebviewWindow，精确域名白名单，并不给远程 WebView 注册危险 Tauri capabilities。

## 正面影响

- 保留软件内浏览体验。
- 远程网站与本地系统权限隔离。
- 登录 Cookie 由服务器管理。

## 负面影响

- 需要处理远程窗口导航、返回和单点登录。
- 下载和外链要单独控制。

## 备选

- 系统浏览器：安全边界更简单，但不满足软件内打开体验。
- 主 WebView iframe：权限边界较差。
