# ADR-0004：服务连接只允许本产品自有 API

## 状态

Proposed

## 背景

用户希望 Codex 在不同国内网络环境中连接境外服务器，但通用 VPN/节点能力会扩大合规、运营和安全风险。

## 决策

优先直接访问自有 HTTPS API；必要时使用 loopback sidecar 和受限接入网关。目标 host 由签名 route manifest 白名单控制，不提供任意流量代理。

## 正面影响

- 只影响 Codex。
- 不修改系统代理。
- 攻击面和滥用范围较小。
- 能与设备权益和 secret broker 集成。

## 负面影响

- 不能解决所有第三方网站可达性。
- 需要自有接入网关和运维。
- 仍需法律和运营评估。

## 备选

- 通用 VPN/机场：不纳入项目。
- 完全依赖用户系统网络：简单，但无法控制自有服务体验。
