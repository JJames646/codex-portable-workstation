# ADR-0001：使用 Codex++ Fork 作为正式客户端底座

## 状态

Proposed

## 背景

产品要求在同一 UI 中保留 Codex++ 的供应商、会话、插件、页面增强和远程项目能力，同时增加 U 盘、服务器、更新和安全退出功能。

## 决策

正式客户端优先直接 Fork Codex++，继续使用 Rust、Tauri 和 React。当前网页原型迁入该工程。

## 正面影响

- 最大复用现有功能。
- 减少双 UI 和跨进程状态同步。
- 与现有原型技术形态接近。

## 负面影响

- 必须履行 AGPL。
- 需要长期同步上游。
- 大型 `App.tsx` 需要逐步 feature 化。

## 备选

- WPF 启动器 + 原版 Codex++：许可边界更清晰，但无法真正统一功能。
- 新 UI 嵌入 Codex++：IPC 和 WebView 边界不稳定。
