# ADR-0002：用户端只使用自己的签名更新源

## 状态

Proposed

## 背景

Codex++、便携 Codex 和其他上游更新频繁，直接更新任何一个组件都可能破坏兼容性。

## 决策

社区更新只在 CI 中监控。用户端只读取自己的 stable/beta 清单，并验证兼容矩阵、SHA-256 和 Ed25519。

## 正面影响

- 可控制兼容组合。
- 可回滚。
- 不依赖用户机器 Git 环境。
- 用户数据不被社区更新覆盖。

## 负面影响

- 需要维护构建和发布基础设施。
- 上游最新版本不会立即到达用户。

## 备选

- 客户端直接 GitHub Release：缺少整体兼容控制。
- 客户端 `git pull`：不适合二进制产品且风险最高。
