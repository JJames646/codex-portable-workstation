# UI 图标来源

- `branding/yunshu-workstation.png`
  - 用户提供的“云枢 AI 便携工作站”品牌图。
- `engines/codex.svg`
  - Lobe Icons `codex-color.svg`，对应 Codex 产品图标。
- `engines/claudecode.svg`
  - Lobe Icons `claude-color.svg`，使用与用户参考图一致的 Claude 橙色放射标志，
    替代原来的 Claude Code 机器人图形。
- `engines/openclaw.svg`
  - Lobe Icons `openclaw-color.svg`，对应 OpenClaw 产品图标。
- `catalog/*.svg`
  - 插件与 Skill 的本地化目录图标，来源为 Lobe Icons、Simple Icons 和
    Font Awesome 的对应公开图标资源。

所有图标均保存为项目本地资源，正式应用运行时不依赖第三方图片 CDN。发布前应继续保留
上游许可证和商标说明，不得使用图标暗示云枢工作站获得对应厂商官方背书。
